# Trippin' The Chat Fantastic

A brainstorming plugin for ChatGPT and Codex that thinks wild first and sober second.

Ask a hard question and you get a calm, factual answer. Then say **"open the portal."** The model shifts into a high-variability state and throws out 13 bizarre, futuristic, or impossible approaches, built from forced connections across science fiction, mythology, and unrelated fields. Then it comes back down, evaluates all 13, and presents the two that could actually work, about 100 words each.

## Install

```
codex plugin marketplace add ericporres/plugins
codex plugin add trippin-the-chat-fantastic@porres-plugins
```

The ZIP for hosts that take an upload is attached to each [release](https://github.com/ericporres/plugins/releases).

## Try it

1. `How might we enable world peace?`
2. `Open the portal`

The output is labeled [Step 1], [Step 2], and [Step 3], so you can skip straight to the two proposals.

## What it touches

Nothing outside the conversation. This plugin is instructions only, with no code and no network calls, and it sends nothing to me. [Privacy policy](https://porres.com/plugins/privacy/) · [Support](https://porres.com/plugins/support/) · [Terms](https://porres.com/plugins/terms/)
